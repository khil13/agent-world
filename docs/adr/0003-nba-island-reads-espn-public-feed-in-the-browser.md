# The NBA island reads ESPN's public feed straight from the browser, with stats only

The NBA island and its props panel read tonight's games, box scores and team leaders' season averages from ESPN's public, keyless scoreboard and summary endpoints, asked for from the visitor's browser. The site stays a static GitHub Pages page with no server of its own. We rejected sportsbook odds through a paid odds API (it needs a key, which would have to sit in a server function like the one in ADR 0001 for a feature that has nothing to do with the agents) and a scheduled job that copies the feed into this repo (it would write to the repo every few minutes during games, and it would never be live). The consequences: lines come from season averages or are typed in by the visitor, never from a book; only the team leaders ESPN lists have an average, so other players have no suggested line; the feed is unofficial and can change shape or stop answering browsers from other sites, in which case the island simply does not appear (all parsing is defensive and tested, in `src/nba.mjs`); and the slip and the averages are kept in the visitor's own browser, never sent anywhere.
