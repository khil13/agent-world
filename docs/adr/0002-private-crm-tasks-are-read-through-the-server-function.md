# Private CRM tasks are read through the server function, for the signed-in Admin only

The task agents of the three CRM repos (their workflows, runs and progress) are shown from a feed served by the same Supabase Edge Function that holds the GitHub token for Activate (see ADR 0001). The function answers only the signed-in owner, only for the three CRM repos, and returns names, states, times and counts, never commit messages, log text or file contents. Visitors who are not signed in see the public world unchanged. We rejected making the CRM repos public (the public page and its browser polling would then just work, but code and data the owner deliberately made private would be exposed) and giving the public dashboard snapshot a token (it would publish private repo names and activity on a public page, and it changes the dashboard repo, which this project treats as read-only). The consequence is that the view of the CRM tasks only exists while the owner is signed in, that the GitHub token needs read access to Actions and to workflow files as well as the right to start runs, and that the world's model of a task comes from a sanitised feed rather than the public `data.json`.
